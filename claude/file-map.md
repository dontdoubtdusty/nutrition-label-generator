# File map

- `index.html` - the whole app: inline CSS, inline JS. Open it in a browser to run. Sections in order: CSS, reference data (daily values, row layout, sample label), label logic (formatting, rounding, percent DV, row building), rendering (DOM), USDA lookup, recipe logic (parser, unit conversion, totals), page state, page wiring (single food), recipe wiring, start.
- `README.md` - what the app is, how to run it, feature list.
- `claude/vision.md` - design doc: decisions, build order, open decisions, out of scope.
- `claude/file-map.md` - this file.
- `claude/session-log.md` - session counter and per-session notes.
